# 🧸 KIDS-BIZ (아동복 온/오프라인 통합 재고 및 매출 관리 반응형 웹앱)

> **Antigravity 바이브코딩 (Vibe Coding)** 기반 아동복 온/오프라인 매장 통합 운영 솔루션  
> 디자인 레퍼런스: [핀터레스트 재고관리 무드보드](https://pin.it/5ywmZbeKY) 준수

---

## 🌟 프로젝트 개요 (Overview)

**KIDS-BIZ**는 아동복 온/오프라인 매장을 동시 운영하는 판매자의 실무 경험(남대문/동대문 사입 현장 및 세무/회계 지식)을 바탕으로 제작된 고성능 반응형 웹앱입니다.

* **온/오프라인 재고 불일치 해결**: 아동복 고유의 5단위 사이즈(XS 5호 ~ XL 13호)별 재고 실시간 동기화
* **야간 발주(사입) 자동화**: 당일 판매 데이터를 기반으로 도매처별 리오더 품목 자동 분류 및 **원클릭 카카오톡 발주서 복사**
* **스마트 가격 및 세금 계산기**: 부가세(10%), 종합소득세 예상 구간, 플랫폼 수수료를 실시간 차감하여 **적정 판매가** 및 **손익분기점 마지노선 최저가** 산출
* **AI 악성 재고 관리**: 14일 이상 판매 정체된 사이즈 자동 감지 및 도매처 맞교환/최대할인가 세일 추천

## 🚀 빠른 시작 (Getting Started)

### 1. 개발 환경 요구사항
* Node.js v18 이상 (권장 v20+)
* npm v9 이상

### 2. 패키지 설치 및 로컬 서버 실행
```bash
# 의존성 패키지 설치
npm install

# 개발 서버 실행 (포트 3000 또는 3001)
npm run dev

# 프로덕션 빌드
npm run build
```

브라우저에서 `http://localhost:3001/` 또는 터미널에 표시된 로컬 주소로 접속합니다.

## 📱 주요 화면 및 기능 안내

### 1. 📊 메인 대시보드 (PRD 3.1)
* **오늘의 총 매출**: 온라인 / 오프라인 판매 건수 및 금액, 전일 대비 증감률(%) 실시간 표시
* **실시간 예상 순수익 (세후)**: 원가, 판매 수수료, 실 납부 부가세(10%), 종합소득세 공제 후 실제 손에 쥐는 순이익 및 마진율(%)
* **총 보유 재고 가치**: 도매 사입 원가 기준 보유 재고의 자산 가치 및 총 보유량
* **미처리 발주 / 교환 알림**: 저녁 사입 품목 및 도매처 14일 교환 규정 임박 알림

### 2. 📦 온/오프라인 통합 재고 & 거래처 관리 (PRD 3.2)
* 아동복 표준 5단위 사이즈(`XS(5호)`, `S(7호)`, `M(9호)`, `L(11호)`, `XL(13호)`) 원클릭 `+` / `-` 증감
* 도매 상태 원터치 토글: `[교환가능]`, `[주문가능]`, `[도매품절]`, `[교환불가]`
* **AI 악성 재고 경고**: 14일 이상 정체된 사이즈에 대해 도매처 맞교환 문자 전송 또는 마지노선 할인가 복사 액션 제공
* **사입 이동 모드 (Field Mode)**: 동대문/남대문 사입 이동 중 흔들리는 환경에서도 터치하기 쉽도록 대형 터치 타겟(min-h 44px) 활성화

### 3. 🧮 스마트 가격 및 세금 계산기 (PRD 3.3)
* 도매 사입 원가, 플랫폼별 수수료율 프리셋 (스마트스토어 5.5%, 쿠팡 10.8%, 에이블리 13%, 오프라인 카드 1.5% 등), 배송비, 목표 마진율, 종합소득세 과세표준 구간 반영
* 세금계산서 수취 여부에 따른 매입부가세 10% 공제 정밀 반영
* 워터폴(Waterfall) 세무 분해표 제공 및 **"이 가격으로 상품 등록"** 연동

### 4. 🌙 일일 판매 및 야간 발주 자동화 (PRD 3.4)
* **빠른 판매 등록 모달**: 온/오프라인 판매 시 즉시 재고가 차감되고 야간 발주서에 자동 연동
* **카카오톡 발주서 원클릭 복사**: 사입 삼촌이나 도매처 사장님께 바로 보낼 수 있는 깔끔한 발주 양식 텍스트 자동 복사

## 🗄️ 데이터베이스 스키마 (Supabase / PostgreSQL)

PRD 5번 지침에 따라 모든 테이블의 열(Column) 이름은 **한글**로 명명되었습니다.  
독립적인 DDL 스크립트는 [`supabase_schema.sql`](./supabase_schema.sql)에 보존되어 있습니다.

### 1. `상품_테이블` (products)
| 컬럼명 | 타입 | 설명 |
|---|---|---|
| `아이디` | uuid (PK) | 고유 식별자 |
| `상품명` | text | 아동복 상품명 |
| `카테고리` | text | 상의, 하의, 아우터, 원피스/세트 등 |
| `도매처명` | text | 남대문 부르뎅, 동대문 혜양 등 |
| `도매처연락처` | text | 도매처 전화번호 |
| `도매원가` | integer | 사입 단가 (원) |
| `적정판매가` | integer | 목표 마진 권장 소비자가 (원) |
| `최대할인가` | integer | 손익분기점 마지노선 최저가 (원) |
| `도매상태` | text | 교환가능, 주문가능, 도매품절, 교환불가 |

### 2. `재고_테이블` (inventory)
| 컬럼명 | 타입 | 설명 |
|---|---|---|
| `아이디` | uuid (PK) | 고유 식별자 |
| `상품_아이디` | uuid (FK) | 상품_테이블.아이디 외래키 |
| `사이즈_XS` | integer | 5호 재고 수량 |
| `사이즈_S` | integer | 7호 재고 수량 |
| `사이즈_M` | integer | 9호 재고 수량 |
| `사이즈_L` | integer | 11호 재고 수량 |
| `사이즈_XL` | integer | 13호 재고 수량 |
| `총재고수량` | integer | 총 보유 수량 |

### 3. `판매_테이블` (sales)
| 컬럼명 | 타입 | 설명 |
|---|---|---|
| `아이디` | uuid (PK) | 고유 식별자 |
| `상품_아이디` | uuid (FK) | 상품_테이블.아이디 외래키 |
| `판매채널` | text | 온라인 / 오프라인 |
| `판매사이즈` | text | XS, S, M, L, XL |
| `판매수량` | integer | 판매 수량 |
| `실제판매가` | integer | 실 결제 단가 |
| `판매일시` | timestamp | 판매 시각 |

### 4. `발주_테이블` (orders)
| 컬럼명 | 타입 | 설명 |
|---|---|---|
| `아이디` | uuid (PK) | 고유 식별자 |
| `도매처명` | text | 거래 도매처 상호 |
| `발주품목내역` | jsonb | 발주 품목 및 수량 배열 |
| `발주상태` | text | 대기중 / 완료 |
| `발주일자` | date | 발주 기준 일자 |

## 🌐 클라우드 배포 (Deployment)

### Vercel 배포
1. 저장소를 GitHub에 푸시합니다.
2. [Vercel](https://vercel.com/)에서 프로젝트를 Import합니다.
3. Environment Variables에 `.env`에 정의된 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`를 등록합니다.
4. Deploy를 클릭하면 수 초 내에 전 세계 글로벌 CDN에 배포됩니다.
